    Implement pure functional state transition rules per D-19, D-49, D-53, D-54, D-60, and D-64 (TCKT-03):
    - `result.ts` (D-54): Generic tagged union `Result<T, E> = { success: true; data: T } | { success: false; error: E }` with `ok()` and `err()` constructor helpers.
    - `errors.ts` (D-19, D-64): Domain error classes and codes (`CANNOT_TRANSITION_INVALID_EVENT`, `CANNOT_COMPLETE_UNVERIFIED_GEOFENCE`, `CANNOT_CLOSE_OPEN_CHILDREN`, `INSUFFICIENT_FUNDS`, `CERTIFICATION_MISSING_OR_EXPIRED`, `UNAUTHORIZED_ROLE`).
    - `guards.ts` (D-64): Transition guard predicates checking precondition assertions before state changes (e.g. verifying geofence is verified before field task completion, verifying all child service requests are completed before closing parent ticket).
    - `service-request.ts` (TCKT-03, D-49): `transitionServiceRequest(currentStatus, event, context): Result<ServiceRequestTransitionResult, DomainError>`. Supports lifecycle: `OPEN -> ASSIGNED -> IN_PROGRESS -> PENDING_APPROVAL -> COMPLETED -> CLOSED`, with branches for `CANCELLED` and `WAITING_OPS_UPDATE`.
    - `ticket.ts` (TCKT-03, D-49): `transitionTicket(currentStatus, event, context): Result<TicketTransitionResult, DomainError>`. Enforces valid event triggers (`ASSIGN_OFFICER`, `START_WORK`, `SUBMIT_FOR_APPROVAL`, `APPROVE`, `REJECT`, `COMPLETE`, `CLOSE`, `CANCEL`, `FLAG_EXCEPTION`).
    - `rollup.ts` (D-53): `calculateTicketRollupStatus(childRequestStatuses: ServiceRequestStatus[]): TicketStatus`.
      - If any child is `WAITING_OPS_UPDATE` -> `WAITING_OPS_UPDATE`.
      - If all children are `COMPLETED` or `CLOSED` -> `COMPLETED`.
      - If any child is `IN_PROGRESS` -> `IN_PROGRESS`.
      - If all children are `CANCELLED` -> `CANCELLED`.
      - Default: `ASSIGNED` or `OPEN`.
