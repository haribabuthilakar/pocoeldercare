## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (Light) / `#0F172A` (Dark) | Page background, modal backdrop overlay, panel background |
| Secondary (30%) | `#FFFFFF` (Light) / `#1E293B` (Dark) | Cards, modal content sheets, navigation surfaces, dropdown menus |
| Accent (10%) | `#12C395` (Primary Mint) | Reserved for specific focus anchors (see below) |
| Destructive | `#FE1D8F` (Alert Magenta) | Reserved for destructive/emergency actions only (see below) |

Accent (`#12C395`) reserved for:
- Primary CTA buttons ("Authorize Payment", "Accept Incoming Call", "Dispatch Test Webhook", "Save Mock Configuration")
- Active payment method tab indicator (UPI / Card / Netbanking)
- Waveform audio player progress bar & live call audio indicator pulse
- Input focus rings and active slider tracks

Destructive (`#FE1D8F`) reserved for:
- "Decline Call" and "End Call" phone controls in Exotel simulator
- "Reset All Configurations" destructive action in Admin testbench
- Emergency SOS indicator badge on incoming senior caller card

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's `## UI Considerations` lift rule. Shape-rooted UI state coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| `empty` | Webhook logs table, Outbound call audit list, Call recordings drawer | ✅ covered | Renders dedicated `@poco/ui` EmptyState component referencing documented empty state copy with clear next-step CTA. |
| `loading` | Razorpay payment authorization, Bank list fetch, Webhook dispatch in-flight, Exotel call connecting | ✅ covered | Renders Skeleton placeholders for grids/cards and animated circular spinner with explicit status text ("Connecting to payment gateway...", "Synthesizing IVR voice..."). |
| `error` | Payment bank decline, HMAC verification failure, Fault injection 500 error, Softphone audio error | ✅ covered | Renders inline Alert banner with explicit failure explanation and actionable recovery paths ("Retry Payment", "Switch Method", "Check Mock Secret"). |
| `populated` | Partner Health Grid (13 cards), Scenario preset list, Popular banks grid (6 banks), DTMF 12-key dialpad | ✅ covered | Renders responsive grid (3-column on desktop >=1024px, 2-column on tablet >=768px, 1-column on mobile <768px) with full metric badges and status chips. |
| `partial` | Incomplete Card details (missing CVV/expiry), Partial call disposition notes, Partial scenario JSON payload | ✅ covered | Form validation errors highlight invalid fields with red border and explicit field error copy; primary submit CTA remains disabled until valid. |
| `overflow` | Raw JSON webhook payload viewer, Outbound call request/response inspector, IVR speech transcript log | ✅ covered | Code and transcript containers use fixed max-height (`max-h-64` or `max-h-96`) with smooth internal vertical scrolling (`overflow-y-auto`) and copy-to-clipboard button. |
| `zero-one-many` | Partner cards list, Active call participants, Available payment methods | ✅ covered | Dynamic pluralized headers (e.g. "12 Active Partners", "1 Incoming Call", "3 Payment Methods Available") and adaptive flex/grid layout. |
| `long-text` | Senior full medical notes on caller ID card, Long transaction error descriptions, Address strings | ✅ covered | Text clamps at 2 lines (`line-clamp-2`) with accessible hover tooltip (`@radix-ui/react-tooltip`) revealing full unabbreviated string. |
