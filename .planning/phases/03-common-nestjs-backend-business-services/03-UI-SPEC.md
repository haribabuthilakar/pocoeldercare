## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (Light) / `#0F172A` (Dark) | Background surfaces, Swagger container, testbench layout backdrop |
| Secondary (30%) | `#FFFFFF` (Light) / `#1E293B` (Dark) | Cards, modal sheets, endpoint panels, data table surfaces |
| Accent (10%) | `#12C395` (Primary Mint) | Reserved for specific focus anchors (see below) |
| Destructive | `#FE1D8F` (Alert Magenta) | Reserved for destructive/emergency actions only (see below) |

Accent (`#12C395`) reserved for:
- Primary CTA buttons ("Test AI Classification", "Upload Test Media", "Authorize Bearer Session", "Execute Job Now")
- Active endpoint tab indicator in Swagger documentation
- Active pg-boss worker status indicators (`RUNNING`, `ONLINE`)
- Form input focus rings and active toggle switches

Destructive (`#FE1D8F`) reserved for:
- "Purge Failed Jobs" action in pg-boss queue monitor
- "Delete Local Upload" action in dev media testbench
- SLA `BREACHED` status chips and emergency SOS alert badges

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's `## UI Considerations` lift rule. Shape-rooted UI state coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| `empty` | Activity feed list, pg-boss job monitor table, Dev media uploads list | ✅ covered | Renders dedicated `@poco/ui` EmptyState component referencing documented empty state copy with clear next-step CTA. |
| `loading` | AI intent classification in-flight, Presigned URL generation, S3 binary PUT progress, Feed delta polling | ✅ covered | Renders Skeleton placeholders for telemetry cards and animated circular spinner with explicit status text ("Classifying message intent with AI model...", "Uploading media to storage..."). |
| `error` | MIME validation failure, Presigned URL expiration, 401 Unauthorized token, AI provider timeout | ✅ covered | Renders inline Alert banner with explicit failure explanation and actionable recovery paths ("Verify JWT Token", "Select Permitted MIME Type", "Switch AI Provider"). |
| `populated` | Active worker queues grid (5 queues), Activity feed timeline items, Endpoint group accordion | ✅ covered | Renders responsive grid (3-column on desktop >=1024px, 2-column on tablet >=768px, 1-column on mobile <768px) with status badges and SLA timer chips. |
| `partial` | Missing X-Household-Id header, Incomplete AI prompt payload, Partial media upload multipart chunk | ✅ covered | Form validation errors highlight invalid fields with red border and explicit field error copy; primary submit CTA remains disabled until valid. |
| `overflow` | Raw JSON API response viewer, AI classification rationale log, Worker stack trace viewer | ✅ covered | Code and log containers use fixed max-height (`max-h-64` or `max-h-96`) with smooth internal vertical scrolling (`overflow-y-auto`) and copy-to-clipboard button. |
| `zero-one-many` | Active worker jobs list, Household activity feed events, Presigned media upload records | ✅ covered | Dynamic pluralized headers (e.g. "5 Active Queues", "1 Unread Feed Item", "12 Uploaded Attachments") and adaptive layout. |
| `long-text` | Long user chat prompts, Detailed AI classification summaries, Nested error stack traces | ✅ covered | Text clamps at 2 lines (`line-clamp-2`) with accessible hover tooltip (`@radix-ui/react-tooltip`) revealing full unabbreviated string. |
