    - `money.ts` (D-23, D-55): Integer paise currency math:
      - `calculateGst(amountPaise: number, gstRatePercent = 18): { basePaise: number; gstPaise: number; totalPaise: number }` (deterministic rounding, no floats).
      - `calculateWalletDebit(currentBalancePaise: number, pricePaise: number, creditLimitPaise: number, isEmergency: boolean): Result<{ newBalancePaise: number; debitPaise: number }, DomainError>`.
      - `formatInr(paise: number): string` formatting paise into standard INR currency strings (e.g. `1250050` -> `₹12,500.50`).
    - `evaluator.ts` (BILL-03, BILL-04, BILL-05, D-50): `evaluateBillingAction(ctx: BillingContext): BillingDecision`:
      - Step 1: Quota check. If available quota units > 0 -> return `{ action: 'AUTO_DEBIT_QUOTA', quotaToDecrement: 1, amountPaise: 0 }`.
      - Step 2: Emergency override check. If `isEmergency` (catalog default or ops override) -> return `{ action: 'EMERGENCY_NEGATIVE_DEBIT', amountPaise: servicePricePaise, allowNegativeBalance: true }` per BILL-03.
      - Step 3: Wallet check. If wallet balance >= servicePricePaise -> return `{ action: 'AUTO_DEBIT_WALLET', amountPaise: servicePricePaise }` per BILL-04.
      - Step 4: Insufficient balance or staff-suggested -> return `{ action: 'REQUIRE_FAMILY_APPROVAL', amountPaise: servicePricePaise, shortfallPaise: servicePricePaise - walletBalance }` placing request in `Pending Approval` per BILL-05.
    - `holds.ts` (D-67): `calculateWalletHold(balancePaise: number, requestedHoldPaise: number): Result<{ holdPaise: number; remainingAvailablePaise: number }, DomainError>` and `calculateHoldSettlement(holdPaise: number, finalCostPaise: number): { debitPaise: number; refundPaise: number }`.
    - `subscription.ts` (D-57): `evaluateSubscriptionRollover(activeQuotas: QuotaAllocation[], basePackageQuotas: PackageServiceQuota[], periodEnd: Date): { resetQuotas: QuotaAllocation[]; expiredUnits: number }` enforcing "Use-It-or-Lose-It" subscription resets.
