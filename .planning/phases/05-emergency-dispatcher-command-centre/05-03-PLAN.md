# Plan 05-03: Timezone-Aware Family Call Tree & 4-State Incident Closure SLA Audit Rollup

## Goal
Implement the automated timezone-aware family escalation tree, the 4-state emergency resolution lifecycle with mandatory clinical outcome documentation, and weekly/monthly SLA compliance audit reporting with family post-mortem incident report generation.

## Requirements Covered
- **EMG-05**: Timezone-aware automated family escalation call tree.
- **EMG-06**: Emergency event closure logging (resolved, hospitalized, false alarm) and weekly SLA performance rollup.

## Tasks
1. **Timezone-Aware Family Escalation Call Tree Engine**:
   - Create pps/ops-crm/src/components/dispatcher/family-escalation-panel.tsx:
     - Calculates local time of NRI children (e.g. US PST/EST, UK, Singapore) and displays local hour badges.
     - Dispatches instant dual WhatsApp + SMS alerts upon incident creation.
     - Executes sequential automated voice call tree (Primary NRI Sponsor -> Secondary Sponsor -> Local Contact) with a 3-minute timeout between tiers.
2. **4-State Incident Resolution Lifecycle & Closure Modal**:
   - Create pps/ops-crm/src/components/dispatcher/incident-closure-modal.tsx:
     - 4 resolution states: RESOLVED_AT_HOME, HOSPITALIZED_AND_ADMITTED, SPECIALIST_TRANSFER, FALSE_ALARM_SOS.
     - Mandatory clinical documentation fields: Attending hospital, admitting doctor name, clinical stabilization summary, and scheduled post-emergency Care Officer follow-up.
3. **Weekly & Monthly SLA Performance Rollup Dashboard**:
   - Create pps/ops-crm/src/app/dispatcher/analytics/page.tsx (or embedded SLA audit report):
     - Visual metrics for Golden Hour arrival compliance rate (% <15 mins), Call-to-ICE retrieval latency (<2s), Dispatcher pickup time (<10s).
     - 1-click Downloadable Family Post-Mortem Incident Report (PDF/CSV).
4. **End-to-End Test Suite for Phase 5**:
   - Create pps/ops-crm/src/__tests__/dispatcher-workflows.spec.tsx covering all 6 EMG requirements.
