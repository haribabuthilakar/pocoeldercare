In `apps/api/src/modules/webhooks/guards/webhook-hmac.guard.ts`: Implement NestJS `CanActivate` guard extracting signature headers (`X-Razorpay-Signature`, `X-Exotel-Signature`, `X-Partner-Signature`), looking up partner secret key from `IntegrationPartner` table, and validating with `verifyWebhookSignature` from `@poco/business-rules` using timing-safe comparison per D-17.
    2. In `apps/api/src/modules/webhooks/webhooks.service.ts`: Implement transactional ingestion:
       - Checks `WebhookEvent` table by `(partnerCode, idempotencyKey)`: if found and status is `PROCESSED`, returns existing response payload with 200 OK immediately without re-executing business logic per D-20.
       - If not found, creates `WebhookEvent` record in `PENDING` state with raw payload.
       - Dispatches to appropriate handler within a database transaction.
       - On success, updates `WebhookEvent` status to `PROCESSED` with `processedAt` timestamp.
       - On failure, updates `WebhookEvent` status to `FAILED` with `errorMessage` and rethrows error.
    3. In `apps/api/src/modules/webhooks/handlers/razorpay-webhook.handler.ts`: Handles `payment.captured` (credits household digital wallet with integer paise amount, creates `WalletTransaction` in ledger, updates payment status) and `payment.failed` per D-12, D-17.
    4. In `apps/api/src/modules/webhooks/handlers/exotel-webhook.handler.ts`: Handles incoming call events (`CallSid`, caller number, IVR digit pressed), auto-looks up senior/household by phone number, auto-creates an inbound Telephony Ticket, and logs call recording URL per D-10, D-12.
    5. In `apps/api/src/modules/webhooks/handlers/loop-closed-webhook.handler.ts`: Handles partner status updates (1mg `DELIVERED`, Orange Labs `REPORT_READY`, Pococare `HOSPITAL_ADMITTED`, Swiggy `DELIVERED`), automatically transitions linked `ServiceRequest` status (e.g. to `Completed`), and writes progress event to household activity feed.
    6. In `apps/api/src/modules/webhooks/webhooks.controller.ts`: Expose routes:
       - `POST /api/webhooks/v1/razorpay`
       - `POST /api/webhooks/v1/exotel`
       - `POST /api/webhooks/v1/pococare`
       - `POST /api/webhooks/v1/:partner` (generic partner loop-closed endpoint)
       All protected with `@UseGuards(WebhookHmacGuard)`.
