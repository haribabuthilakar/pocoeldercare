# Plan 01-02: NestJS Core API, Auth/RBAC, Household & Dynamic SOP Engine

<objective>
Build the core NestJS REST API with Phone/OTP & Email/Password authentication, multi-role RBAC guards, Household & Member onboarding, sub-2-second ICE medical profile CRUD with Redis caching, and dynamic versioned SOP template catalog endpoints.
</objective>

<tasks>

<task id=-02-01\ wave=\>
<title>Scaffold NestJS application and global middleware</title>
<action>
In apps/api:
1. Scaffold NestJS 10 application with Express, CORS, Helmet, and global ValidationPipe (class-validator).
2. Implement global HttpExceptionFilter and JSON response formatter.
3. Configure PrismaModule and RedisModule for shared database and cache connections.
</action>

<threat_model>
- **T-01-03 (Authentication Bypass):** Risk of forged JWT tokens. Mitigation: Strong secret validation with asymmetric or high-entropy HMAC keys, and token revocation via refresh token rotation.
- **T-01-04 (Unauthorized ICE Access):** Risk of exposing sensitive health records. Mitigation: Strict RBAC ensuring only verified family members, assigned Care Officers, and Command Centre Dispatchers can read ICE records.
</threat_model>
