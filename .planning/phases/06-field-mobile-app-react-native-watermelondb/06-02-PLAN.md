<threat_model>
ASVS Level: 1
Threats Considered:
- **SEC-03 (Spoofed Visit Check-ins & Premature Household Activation):** Fraudulent check-ins from outside service zones or unauthorized household activation.
  - Mitigation Task: Task 1 logs raw GPS coordinates and device timestamp in the audit payload for backend discrepancy detection; Task 2 enforces mandatory onboarding SOP completion verification before enabling the Activate Household CTA.
- **SEC-04 (Direct S3 Storage Abuse):** Upload of unvalidated or oversized binary files to S3.
  - Mitigation Task: Task 3 requests presigned PUT URLs with restricted content-types and max filesize constraints, using client-side image compression before S3 dispatch.
</threat_model>
