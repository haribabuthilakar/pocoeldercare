## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, tight tag padding |
| sm | 8px | Chip gaps, list item compact margins, step checkmark spacing |
| md | 16px | Card body padding, input field vertical gaps, standard margins |
| lg | 24px | Section header spacing, screen horizontal gutters |
| xl | 32px | Wizard step separation, modal card vertical margins |
| 2xl | 48px | Primary mobile touch targets, floating action button height |
| 3xl | 64px | Top banner hero clearance, drawer top inset clearance |

Exceptions: 48px minimum touch target size for field ergonomics (`minTouchTarget: 48px`).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|

| Body | 16px (1.000rem) | 400 (Regular) | 1.50 (24px) | Visit instructions, clinical notes, feed messages, list copy |
| Heading | 20px (1.250rem) | 600 (Semibold) | 1.25 (25px) | Screen titles, senior card names, SOP step titles |
| Display | 28px (1.750rem) | 600 (Semibold) | 1.20 (34px) | Vital metric numerals, emergency alert headers, PIN pad numerals |

## Color

60/30/10 spatial balance anchored by canonical @poco/design-tokens:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (Slate 50) | Main application canvas, screen background, scrollable views |
| Secondary (30%) | `#FFFFFF` (Pure White) & `#F1F5F9` (Slate 100) | Surface cards, drawer background, bottom sheets, header bars |
| Accent (10%) | `#12C395` (Primary Mint) | Reserved strictly for: Primary CTA buttons ("Start Visit", "Complete Step", "Upload Proof", "Finish Visit"), active tab indicators, and progress completion bars |
| Emergency / Alert | `#FE1D8F` (Alert Magenta) | Reserved strictly for: Emergency ICE alert banners, critical vitals out-of-range chips, and "Report Exception" blocker buttons |
| Healthcare Secondary | `#6BAAD0` (Cerulean Blue) | Reserved strictly for: Informational status badges, telephony call triggers, and secondary links |
| Destructive | `#DC2626` (Red 600) | Reserved strictly for: Irreversible action confirmation (e.g. discard local unsynced draft) |

Accent reserved for: Primary action buttons ("Start Visit", "Complete Step", "Upload Proof", "Finish Visit"), active tab indicators, and wizard progress bar fills.
