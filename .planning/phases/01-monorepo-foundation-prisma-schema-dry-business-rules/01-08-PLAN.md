<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Database Seeding & Production Guard | Seed reset and test fixtures must never run against production databases. |
| Nginx Reverse Proxy Boundary | Inbound Internet traffic terminates at Nginx with rate limiting and security headers before routing to internal services. |
| Container Memory Bounds | Container memory limits prevent memory spikes from triggering Linux OOM killer on 1GB droplet. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-SC | Tampering | npm dependencies (bcrypt) | high | mitigate | Synchronized package versions and verified bcrypt hashing. |
| T-01-19 | Elevation of Privilege | packages/database/src/seed.ts | critical | mitigate | Strict NODE_ENV !== 'production' check preventing test seed accounts or resets in production environments (D-136). |

| T-01-21 | Information Disclosure | docker/backup.sh | high | mitigate | Gzip compression and encrypted S3 upload with IAM scoped bucket credentials (D-152). |
</threat_model>
