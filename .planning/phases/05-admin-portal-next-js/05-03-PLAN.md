<threat_model>
ASVS Level: 1
Threats Considered:
- **SEC-04 (PII / Medical Data Leakage in Raw DB Viewer):** Administrative personnel inspecting `/admin/database` accessing raw unmasked 12-digit Aadhaar numbers, PAN cards, or payment credentials.
  - Mitigation Task: Task 3 implements client and API-level sanitization filters that automatically mask sensitive PII (`XXXX-XXXX-1234` for Aadhaar, `***` for sensitive tokens) in both table cells and JSON view blocks.
- **SEC-01 (Privilege Escalation):** Unauthorized non-admin staff attempting to view raw database tables.
  - Mitigation Task: Task 3 restricts database explorer routes to `SUPER_ADMIN` role and verifies backend authorization.
</threat_model>
