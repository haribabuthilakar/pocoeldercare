# Plan 01-01: Monorepo Foundation, Prisma Schema & 90-Service Seed

<objective>
Establish the core Turborepo monorepo workspace with pnpm, PostgreSQL 16 & Redis 7 Docker compose environment, shared TypeScript contracts (@poco/types), and the complete relational Prisma database schema (@poco/database) pre-seeded with all 90 services from the Pococare matrix and realistic multi-city Indian personas.
</objective>

<tasks>

<task id=" 01-01-01\ wave=\>
<title>Initialize Turborepo monorepo structure and shared config</title>
<action>
Create the root package.json, pnpm-workspace.yaml, turbo.json, and shared configuration packages:
1. Setup workspace packages: apps/* and packages/*.
2. Configure packages/config with shared tsconfig.base.json, ESLint, and Prettier rules.
3. Configure packages/shared-types with core domain enums (UserRole, PlanTier, ServiceCategory, ExecutionStatus, SopStepType, TransactionType) and REST DTO interfaces.
</action>

<automated>pnpm -v</automated>

<task id=-01-02\ wave=\>
<title>Design complete PostgreSQL schema via Prisma ORM</title>
<action>
In packages/database/prisma/schema.prisma, implement the relational data model:
1. User, Role, UserRoleMapping supporting multi-role context switching.
2. Household, Member, Address, EmergencyContact.
3. IceProfile (encrypted medical conditions, allergies, baseline vitals, attending doctors, preferred hospitals).
4. ServiceCatalog (90 services with unit price, category, SLA minutes, allowed roles).
5. PlanTier (Kavach, Sahara, Sampoorna, Nivas) and PlanQuota (included quotas per plan).
6. Subscription and SubscriptionQuotaLedger for tracking real-time usage and decrements.
7. Wallet and WalletTransaction (HOLD, DEBIT, CREDIT, REFUND) with integer paise balances.
8. SopTemplate (version, title, jsonSchema) and ServiceExecution (status, scheduledAt, completedAt, isDrill, checklistData).
9. ClinicalConsult and Prescription linked to ServiceExecution for doctor visits and teleconsults.
10. VitalsReading for BP, SpO2, Blood Sugar, Pulse, Weight, Temperature.
</action>
<verify>
<automated>pnpm --filter @poco/database prisma validate</automated>
</verify>
</task>

<threat_model>
- **T-01-01 (Data Integrity & Precision):** Risk of floating point rounding errors in financial transactions. Mitigation: Store all currency in integer minor units (paise).
- **T-01-02 (SOP Immutability):** Risk of modifying past visit protocols. Mitigation: Unique composite key on (serviceCatalogId, version) with append-only template versioning.
