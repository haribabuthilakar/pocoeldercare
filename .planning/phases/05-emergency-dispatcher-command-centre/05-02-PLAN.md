# Plan 05-02: Tiered Ambulance Dispatch Engine & Clinical Hospital Pre-Brief Handover

## Goal
Implement the 1-click tiered ambulance dispatch coordination engine and standardized clinical hospital pre-briefing generator. Enables dispatchers to initiate Tier 1 private ALS/BLS hospital fleet dispatch with 108 emergency fallback, generate printable/email hospital ER pre-brief summaries, and monitor live visual SLA response countdowns with supervisor breach escalation.

## Requirements Covered
- **EMG-03**: One-click BLS ambulance dispatch and hospital pre-brief sheet transmission.
- **EMG-04**: Live visual countdown timer against published response SLAs with supervisor auto-escalation.

## Tasks
1. **Tiered Ambulance Dispatch Controller**:
   - Create pps/ops-crm/src/components/dispatcher/ambulance-dispatch-modal.tsx:
     - Tier 1: Empanelled private ALS/BLS hospital fleets (Apollo, Manipal, Fortis) with live GPS ETAs (<15 min arrival SLA).
     - Tier 2: Government Emergency 108/112 1-click fallback dialer with auto-copied GPS coordinates and senior address.
2. **Clinical Hospital Pre-Brief Summary & PDF Dispatch**:
   - Create pps/ops-crm/src/components/dispatcher/hospital-prebrief-sheet.tsx:
     - Standardized clinical emergency briefing containing Senior demographics, blood group, chronic conditions, drug allergies, active prescriptions, ECG history, and dispatcher triage notes.
     - 1-click printable PDF view and automated dispatch email to the trauma ER receiving desk.
3. **Live SLA Visual Countdown Timers & Supervisor Escalation**:
   - Create pps/ops-crm/src/components/dispatcher/sla-countdown-tracker.tsx:
     - Monospace tabular countdown timers (ont-mono tabular-nums) tracking Call Pickup (<10s), ICE Retrieval (<2s), Ambulance Dispatch (<3 mins), and Golden Hour On-Ground Arrival (<15 mins).
     - Visual #FE1D8F glowing alerts and automatic supervisor escalation when timer breaches the 3-minute critical threshold.
4. **Unit & Integration Tests**:
   - Test ambulance tier selection, pre-brief PDF payload compilation, and SLA countdown countdown arithmetic.
