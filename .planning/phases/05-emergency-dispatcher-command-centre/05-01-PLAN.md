# Plan 05-01: Exotel CTI Inbound Screen Pop & Sub-2s Senior ICE Retrieval Engine

## Goal
Implement the core low-latency emergency caller identification system and dispatcher screen pop interface. When an inbound emergency helpline call or device SOS webhook arrives, the system maps the Exotel caller ID in <2 seconds, presents an urgent screen takeover modal with audio/visual alert, and pre-loads the senior's full encrypted ICE profile with multi-senior household disambiguation.

## Requirements Covered
- **EMG-01**: Real-time emergency queue with priority ranking for device alerts (fall/SOS) and inbound PSTN calls.
- **EMG-02**: Exotel CTI caller ID mapping displaying member identification and ICE profile in < 2 seconds.

## Tasks
1. **Dispatcher App Shell & Real-Time Inbound Queue Component**:
   - Create pps/ops-crm/src/app/dispatcher/page.tsx (or dedicated dispatcher command view) with real-time incoming alert stream, priority tags (SOS_DEVICE, INBOUND_PSTN, OFFICER_PANIC), and active dispatcher console.
2. **Exotel CTI Caller ID Mapping Service & Webhook Simulator**:
   - Create caller identification lookup resolving incoming phone numbers to household IDs and primary senior records with sub-2s cached lookup.
3. **Urgent Screen Takeover Modal Component**:
   - Create pps/ops-crm/src/components/dispatcher/emergency-screen-pop.tsx:
     - High-visibility modal with pulsating #FE1D8F glowing border and audio alert chime.
     - Live caller telemetry, call duration counter, and Exotel caller ID display.
     - Multi-senior household disambiguation tabs for residences with multiple elders.
4. **Sub-2s Senior ICE Medical Emergency Panel**:
   - Instant display of blood group (O+), chronic conditions, critical drug allergies (Penicillin), primary NRI sponsor contacts, and direct ER lines.
5. **Unit & Integration Tests**:
   - Verify <2s ICE resolution, multi-senior tab switching, and caller ID parsing in Vitest.
