<threat_model>
ASVS Level: 1
Threats Considered:
- **SEC-01 (Privilege Escalation):** Unauthorized staff (e.g. Sales Lead) attempting to access operations queues or approve tickets.
  - Mitigation Task: Task 1 and Task 2 enforce client navigation filtering by `UserRole` and pass session Bearer tokens to NestJS backend where `@Roles(UserRole.OPS_MANAGER, UserRole.SUPER_ADMIN)` guards execute independent authorization checks.
- **SEC-05 (CSRF & Session Hijacking):** Stolen or unvalidated session tokens used in background polling.
  - Mitigation Task: Task 1 encapsulates API requests inside `api-client.ts` with credentials, `SameSite=Strict` token management, and error interceptors for automatic redirect to `/admin/login` on 401/403.
</threat_model>
