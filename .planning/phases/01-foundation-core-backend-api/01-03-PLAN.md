<threat_model>
- **T-01-05 (Financial Double Spend):** Risk of race condition in wallet debits under concurrent requests. Mitigation: Interactive database transaction with row-level locking (SELECT ... FOR UPDATE).
- **T-01-06 (Emergency Drill Confusion):** Risk of drill triggering actual ambulance dispatch. Mitigation: Guard check enforcing is_drill === true aborts external integration dispatch calls.
</threat_model>
