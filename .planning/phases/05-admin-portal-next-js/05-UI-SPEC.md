## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F8FAFC` (Light Slate Background) / `#0F172A` (Dark Slate Navigation) | Main page background, data table container backdrops, sidebar panel background |
| Secondary (30%) | `#FFFFFF` (White) / `#1E293B` (Dark Slate Card) | Cards, data table rows, modal content sheets, dropdown menus, filter panels |
| Accent (10%) | `#12C395` (Primary Mint) | Reserved for specific focus anchors (see below) |
| Destructive | `#FE1D8F` (Alert Magenta) | Reserved for destructive / emergency actions only (see below) |

Accent (`#12C395`) reserved for:
- Primary CTA buttons ("Confirm Triage", "Publish New Catalog Version", "Assign Care Officer", "Dispatch Test Payload", "Resolve Rollup Exception")
- Active navigation tab and sidebar indicator pills
- Inline 1-click Quick Approve button on high-confidence AI triage suggestions
- Input focus rings and active toggle switch thumbs
- Refresh queue live status indicator pulse

Destructive (`#FE1D8F`) reserved for:
- "Dismiss AI Suggestion" button in triage queue
- Emergency override toggle indicators and fall alert badge chips
- "Cancel Service Request" confirmation button in ticket editor
- "Purge Failed Jobs" button in background queue inspector
